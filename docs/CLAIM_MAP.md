## Current implementation (after the 2026-10-06 rebuild)

Every element is implemented in the product code and covered by tests. The prototype algorithm for each element is preserved behaviour-for-behaviour in `packages/core/src/interview_core/legacy/`, and characterization tests pin it by running the original prototype code side by side (`packages/core/tests/characterization/`).

**Accuracy has not been measured for any element yet, because no consented evaluation data exists** (see `docs/EVAL_REPORT.md`). "IMPLEMENTED" here means the mechanism works on real inputs and is tested. It is not an accuracy claim.

The spoken interview runs over one WebSocket (`services/api/src/interview_api/live.py`): browser mic → server VAD and speech recognition → interviewer agent → TTS → browser. Each answer then flows through `interview.advance` → `answer_signals` (E3, E4, E5, delivery) → the agent (E6) → report (E9).
